# DayDone 项目说明

## 项目目标

一个手机端优先的生活打卡应用，默认记录三件日常小事，也支持用户添加自己的打卡项目。数据只保存在当前浏览器的 `localStorage` 中，不依赖后端和数据库。

## 当前功能

- 首页显示当天日期、打卡项目和完成进度
- 默认项目：上大号、洗澡、洗衣服
- 自定义项目的新增、编辑和删除
- 删除项目时保留历史记录，项目配置以归档方式保留
- 最近 7 天打卡记录
- 月历视图、月份切换和每日完成标记
- 点击日历日期查看当天各项目状态
- 刷新页面后保留记录和自定义项目
- 兼容第一版 `daydone.records.v1` 历史数据

## 技术栈

- Vue 3
- Vite
- JavaScript
- 原生 CSS

## 运行项目

```bash
npm install
npm run dev
```

npm run build

```

src/
  App.vue                  应用状态、视图切换和数据操作
  components/
    HomeView.vue           首页、打卡卡片和最近 7 天
    CalendarView.vue       月历、月份切换和日期详情
    ItemManager.vue        自定义项目的新增、编辑和删除

  main.js                  Vue 应用入口
  styles.css               移动端优先的全局样式
```

## 数据约定

记录数据继续使用第一版存储键：

```text
daydone.records.v1
```

结构保持不变，日期为唯一键，项目 ID 对应布尔值：

```json
{
  "2026-09-16": {
    "toilet": true,
    "shower": false,
    "laundry": true,
    "custom-...": false
  }
}
```

自定义项目配置使用新存储键：

```text
daydone.items.v1
```

项目配置包含名称、Emoji、是否默认、是否归档以及创建和归档日期。第一版数据不需要迁移，读取时缺失的项目字段按未完成处理，未知的布尔字段会保留，避免删除自定义项目时丢失历史记录。

## 数据规则

- 默认日期键使用本地时间，避免 UTC 日期偏移。
- 默认项目不能被编辑或删除。
- 自定义项目删除后从首页隐藏，但历史记录和项目元数据继续保留。
- 日历日期详情只显示该日期适用或已经有历史字段的项目。
- 存储内容损坏时回退到默认项目或空记录，页面继续运行。
