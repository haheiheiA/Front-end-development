# DayDone 项目说明

## 项目目标

一个手机端优先的生活打卡页面，每天记录三件事：

- 上大号
- 洗澡
- 洗衣服

数据只保存在当前浏览器的 `localStorage` 中，不依赖后端和数据库。

## 技术栈

- Vue 3
- Vite
- JavaScript
- 原生 CSS

## 运行项目

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 主要结构

```text
src/
  App.vue       页面状态、打卡逻辑和最近 7 天记录
  main.js       Vue 应用入口
  styles.css    移动端优先的全局样式
```

## 数据约定

- 存储键：`daydone.records.v1`
- 数据结构：

```json
{
  "2026-09-16": {
    "toilet": true,
    "shower": false,
    "laundry": true
  }
}
```

日期使用本地时间的 `YYYY-MM-DD` 作为唯一键，因此同一天只会有一份记录。读取到不完整或损坏的数据时会按未完成处理，避免页面无法启动。
