# JobTrack 项目开发规则

## 项目定位
JobTrack 是一个用于个人求职管理的 Web 应用。

## 技术栈
- Vue 3
- Vite
- Vue Router
- Pinia
- 原有项目依赖优先
- 不随意新增依赖

## 开发原则
- 简单 > 复杂
- 实用 > 炫技
- 稳定 > 大规模重构
- 快速迭代 > 一次性做完
- 优先复用现有代码
- 不做与当前任务无关的重构

## 修改原则
- 只修改完成任务所需的文件
- 不随意修改项目架构
- 不随意更换技术栈
- 不删除已有功能
- 不改变已经确定的页面设计
- 如果发现需要大规模修改，先说明原因

## 完成任务后
- 检查代码
- 尽可能运行项目现有检查命令
- 汇报修改文件
- 汇报主要修改内容
- 汇报验证结果
- 如果存在未解决问题，明确指出
