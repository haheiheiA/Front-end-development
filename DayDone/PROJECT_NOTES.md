# DayDone 项目说明

## 项目目标

一个手机端优先的生活打卡应用，默认记录三件日常小事，也支持用户添加自己的打卡项目。数据只保存在当前浏览器的 `localStorage` 中，不依赖后端和数据库。

## 当前功能

- 首页显示当天日期、打卡项目、完成进度和最近完成时间
- 默认项目：上大号、洗澡、洗衣服
- 自定义项目的新增、编辑和删除
- 删除项目时保留历史记录，项目配置以归档方式保留
- 每个项目显示上次完成时间和相对时间
- 最近 7 天打卡记录
- 月历视图、月份切换和每日完成标记
- 点击日历日期查看当天状态和备注
- 打卡后不自动打开备注，用户主动点击“添加备注”后编辑或删除备注
- 当前月份总打卡次数和每个项目的完成统计
- 导出和导入 JSON 备份
- 二次确认后清空本地数据
- 完成当天最后一个启用项目时显示 Pingu 庆祝界面
- 刷新页面后保留记录、备注和自定义项目
- 兼容第一版和第二版的历史数据

## 技术栈

## 数据约定

记录数据继续使用第一版存储键：

```text
daydone.records.v1
```

原有布尔字段保持不变：

```json
{
  "2026-09-16": {
    "toilet": true,
    "shower": false,
    "laundry": true,
    "custom-...": false
  }
}
```

第三版在日期记录中增加保留字段 `_meta` 保存完成时间和备注：

```json
{
  "2026-09-16": {
    "toilet": true,
    "_meta": {
      "toilet": {
        "completedAt": "2026-09-16T14:30:00.000Z",
        "note": "今天状态不错"
      }
    }
  }
}
```

自定义项目配置继续使用：

```text
daydone.items.v1
```

备份文件使用 `daydone-backup` 格式，包含项目配置、所有日期记录、完成时间和备注。导入时会先解析和校验，只有校验通过并确认后才替换当前数据。

## 数据规则

- 日期键使用本地时间，避免 UTC 日期偏移。
- 旧记录没有 `_meta` 时仍按原布尔值正常显示。
- 旧记录不会因为升级而被补写或修改完成时间。
- 新打卡才写入 `completedAt`，相对时间只用于显示计算。
- 备注最长保留 300 个字符。
- 默认项目不能编辑或删除。
- 自定义项目删除后从首页隐藏，但历史记录和元数据继续保留。
- 存储或导入内容损坏时不会覆盖现有数据。
- 庆祝状态只存在当前页面内存中，不写入本地存储，刷新不会重复弹出。
